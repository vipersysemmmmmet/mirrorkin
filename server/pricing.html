What AI usage costs to run

Estimate assumes 5,000 input tokens and 700 output tokens per reply, at $4 / million input tokens and $20 / million output tokens. Actual usage varies with conversation length, screenshots, and web searches. Starter's 2-day maximum is 20 replies, or about $0.68 at this estimate.

Model rates checked October 26, 2026 against Anthropic's API pricing. Hosting, storage, payments, Scout research and taxes are not included.

Important: These are usage estimates, not included prepaid credit or a guaranteed bill. Paid chat caps are set below the plan prices using these assumptions, but real prompts, image inputs, and tool calls can cost more.
